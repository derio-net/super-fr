# Image prompt pack — factory series (portrait, right-side)

How to use: run all prompts in the SAME ChatGPT session, with
`docs/presentation/diagrams/factory-line.png` attached to every prompt
(or as the session's style reference). Shared rules (do not repeat per
prompt): same dark factory, same flat technical illustration style, same
chassis model, palette near-black `#0d1117` + blue `#58a6ff` + green
`#7ee787` + warm lamp glow, yellow robots, no people, no readable text
except station plates, PORTRAIT 3:4 composition, subject centered, edges
falling to pure `#0d1117` so the slide's right side blends seamlessly.

The halo rule (upgrades only): everything renders in normal lighting
EXCEPT the named new piece, which carries a bright green halo —
glowing outline plus soft light spill onto its surroundings. Same halo
in every upgrade image, no exceptions.
