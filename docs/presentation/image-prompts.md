# Image prompt pack — factory series (independent prompts)

Each prompt below is SELF-CONTAINED: run any one of them alone, in any
session, with `docs/presentation/diagrams/factory-line.png` attached as
the style reference. If the session has no memory of the others, add
this line at the top of your message:

> Match the attached reference image exactly: dark industrial automotive
> factory, flat technical illustration, same car chassis model, palette
> near-black `#0d1117`, blue `#58a6ff`, green `#7ee787`, warm lamp glow,
> yellow robots.

The halo rule (upgrades only): everything in normal lighting EXCEPT the
named new piece, which carries a bright green halo — glowing outline
plus soft light spill onto its surroundings.
