# Triage batch adopt

One agentic phase (fr-goal-light). It builds `fr triage batch adopt`, which puts a
running, hand-started herdr session under the wave driver without launching a second
session. The work runs bottom-up: the runner protocol first, then the branch rename
fr needs for its own state, then the event and its readers, and last the verb, with
`--list` and the skill. Every task is test-first. The live proof is the post-merge
sweep of the operator's six sessions (spec Test Plan step 4).
