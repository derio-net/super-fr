### disc-dogfood · discovery · The bug reproduced on this plan's own scaffolding — live evidence, not a fixture

This plan was scaffolded by the very command it fixes. The phases file declared a tier on all five phases (standard/standard/standard/hard/standard). After 'fr plan create --phases-file' at fr 4.8.0: 01.yaml kept skeleton AND acceptance and lost tier; 02-05.yaml kept acceptance and lost tier. Zero tier keys across five phases, exit 0, no warning. The tiers were then restored by hand — the exact workaround gh#434 reports being applied three times in another repo. They were inserted as the LAST header key, where the fixed emitter will write them, so a future re-scaffold of this plan is byte-identical rather than merely equivalent.
