### d1-state-home · decision · Triage state lives in a per-scope local cache, never committed

Operator chose the local cache: ~/.cache/fr/triage/<scope>/ with scope derio-net--super-fr (repo) or derio-net (org), mirroring the <org>--<repo> marketplace convention. Consequences: triage state is not a sixth artifact kind, so no registry entry, stamp, migration or structure validator; org scope has a natural home; triaging an employer or customer org cannot leak into a public repo (third-party-privacy). A --dir flag overrides the location for anyone who wants it in git. Rejected: committed under docs/superpowers/triage/ — reviewable, but a new registered artifact kind and no home for org scope.

### d3-status-derived · decision · Stages are derived from GitHub; notes live in the judgement YAML; the page is read-only

Operator chose derived status. Stage is computed from collected facts on every collect (open, PR draft, PR ready, merged, closed); notes are a field in the judgement YAML the operator or agent edits; the rendered page is read-only and re-rendered to update. One source of truth the agent can read. Rejected: in-page dropdowns persisted to browser localStorage — edits would live only in one browser, invisible to the agent and to fr triage, two sources of truth that silently diverge. This is a deliberate difference from the Artifact board, which had a shared server-side store a local file cannot have.
