# Presentation showdown — experiment protocol plan

Neutral fair-fight protocol for the half-and-half deck. The demo feature is
demo ticket (brief deferred — operator fills `experiment/prompts/goal.md` during
repo prep). Both runs pin OpenAI Terra at default effort, log every operator
clarification without cap, and record via asciinema for a HyperFrames
side-by-side edit. The comparison table is filled from measurements only; the
deck closes by asking whether the ceremony is worth it at current model
capability, never by asserting a winner.
