# Triage open PRs plan

Each phase is TDD red-green with a walking skeleton first. Collect gains an
open-only bulk call (closed history untouched), anchors resolve deterministically
from the PR file list with bodies read at the head ref only on match, judgements
reuse the `<repo>#<n>` grammar with a delivery verdict, and render adds badges
plus a PRs section. The skill, both mirrors, a minor bump, and matrix rows ship
in the same PR; live board walks stay operator-driven in the trailing manual
phase.
