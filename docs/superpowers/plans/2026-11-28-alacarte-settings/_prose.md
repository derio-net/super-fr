# À la carte settings — implementation plan

One agentic phase: the spec's three asks (disabled workflows, PR-body sections, stealth
confirmation) share one schema bump and one settings model, and the whole change is reviewable
as one diff. Tasks follow the spec's Design sections A–F in order: schema 3 first (every later
task reads the new keys), then the placement text, the workflow refusal, the PR-body sections,
the stealth loader/check/push changes, and last the skills, mirrors, docs and the candidate
scenario that walks all three rows.
