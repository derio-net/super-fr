The five largest modules, and where their parts go

Authored on 2026-11-16 from the architecture review of #1318. Five modules hold about 24,000 of the 142,500 lines under packages/*/src. Each has a part that moves cheaply along a seam the code already has, and a part that is costly for a reason the review names. Nothing is split yet: the table is the plan, and the review holds the line ranges, the slice order and what each slice must keep.

Module Lines What stays What moves, and where Guard
commands/run_cmd.py 8,862 the resolve and advance coordinators, which own the order of saves, commits and output; the Typer commands the write ledger to fr/run/writes.py now; lookup helpers, deliver gates (fr/run/deliver.py), briefs (fr/run/brief.py) and evidence verifiers (fr/run/evidence/) only once they refuse through a typed verdict instead of printing and exiting, because nothing under fr/run/ imports typer or a console line budget; the journal-writer list in test_journal_stamp_offset.py
commands/triage_batch_cmd.py 7,334 the factories and clock tests patch, build_driver, one_pass, pass_exit, the commands dispatch_batch and adopt_batch to fr/triage/batch_*.py, and the 3,132-line _Driver, split into mixins, to fr/triage/batch_driver*.py; all of it only after the driver takes every effect (forge, runner, clock, state, output, and the fr_dispatch work items) through one ports object. Replace and recovery stay line budget; the batch-module globs that keep git in gitseam and forge writes in the adapter
isolation/local.py 3,164 the target class: up, down, teardown order, worktree provisioning, default branch runner plumbing, landing analysis, branch classification and reap types to new isolation/ modules; garbage collection to a collaborator; the four methods the host-worktree target overrides stay on the target, and the sweeper calls them there line budget; the forge-argv and VK scans that name the file
plan_ops.py 2,545 the writers: create, tracking issue, rework self-review to fr/plan/review/; the spec table to fr/spec_table.py; the refactor-gate read to fr/record/gates.py. Retiring tick and complete_phase changes behaviour and needs its own spec line budget
triage/batch_drive.py 2,130 drive_pass, Snapshot and Action: one planner the wave-export and hand-back leaves to batch_drive_*.py line budget; the pure-pass guard, widened to a glob in the same change

The line budget (tests/unit/test_tripwire_module_budget.py) holds each of these five at most at its budget, which starts at its size rounded up to the next hundred, and no more than 400 lines above it. It is a review trigger, not a ceiling for the codebase: a change that adds past the headroom moves code out or raises the budget in its own diff, and an extraction lowers it.
